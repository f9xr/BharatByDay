# भारतByDay 🇮🇳

**One unique spot in India to explore, every single day.**

भारतByDay is an open-access travel journal from the **F9XR Editorial Team** that publishes one researched, offbeat destination every day — from hidden stepwells and forgotten valleys to local culture the guidebooks miss.

Live site: <https://f9xr.github.io/BharatByDay>

## Features

- Daily posts, each with practical logistics (location, route, best season, permits) and the story of the place
- **On-site search** — full-text search over every post at `/search/`
- **Related articles** — posts matched by shared tags
- **Open comments** — GitHub-backed [utterances](https://utteranc.es) threads under every post
- **E-E-A-T structured data** — JSON-LD for `WebSite` (+ SearchAction), `Organization`, and `BlogPosting`
- **Atom & RSS feeds** — `atom.xml` and `feed.xml`
- **Author page** for the F9XR Editorial Team at `/author/f9xr/`
- Dark / light theme toggle, reading progress bar, back-to-top, and code copy buttons
- SEO via `jekyll-seo-tag`, `jekyll-sitemap`, and `jekyll-feed`

## Getting started

```bash
gem install jekyll bundler
bundle install
bundle exec jekyll serve
```

Open <http://localhost:4000/BharatByDay>.

### Writing a new post

Add a file to `_posts/` following the naming convention `YYYY-MM-DD-your-slug.md`:

```markdown
---
layout: post
title: ...
description: "One-sentence meta description shown under the title."
tags: [Rajasthan, Heritage]
---
# Heading (auto title also works)

Body text goes here. Markdown is supported.
```

The `description` front matter is used for SEO meta tags, cards, search snippets, and the subtitle under each post title.

## Project structure

```
_config.yml        site config, socials, feeds, SEO
_includes/         header, footer, head, nav & share links
_layouts/          default, home, post, page, author, search
_posts/            daily articles (YYYY-MM-DD-slug.md)
css/override.css   complete design system (dark + light)
js/                main.js (UX), search.js (search)
search.json        generated full-text search index
atom.xml           Atom feed (generated by jekyll-feed)
feed.xml           RSS mirror of the Atom feed
author.md          author page at /author/f9xr/
```
